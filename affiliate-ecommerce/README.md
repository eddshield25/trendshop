# Affiliate E-Commerce Platform

A modern e-commerce platform for managing and selling affiliate products from TikTok, Amazon, and other sources.

## 🚀 Features

- **Affiliate Product Management**: Add products from TikTok, Amazon, and other platforms
- **Bulk Upload**: CSV/Google Sheets integration for mass product imports
- **Admin Panel**: Complete admin interface for product management
- **Modern UI**: Engaging shopping experience with Tailwind CSS
- **Responsive Design**: Mobile-first approach
- **Real-time Search**: Advanced product filtering and search

## 🛠 Tech Stack

### Frontend
- React 18
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- React Query

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Cloudinary (for image uploads)
